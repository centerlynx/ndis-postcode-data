# NDIS Postcode-Level Insights

## Overview

This repository provides a postcode-level dataset scraped from the publicly available NDIS Care Sector Demand Map:

https://caresectordemandmap.dss.gov.au/map/ndis/lga

It exists because the official NDIS payments dataset is heavily aggregated and suppressed to protect participant identity, which makes postcode-level analysis impractical. This project reconstructs geographically useful signals from alternative public NDIS sources that are not subject to the same suppression.

https://dataresearch.ndis.gov.au/datasets/payments-datasets
